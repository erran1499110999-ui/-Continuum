# Continuity 体检（ST 插件）测试指引 —— 内部快测版

> 仅供创始人社交圈测试使用，不对外发布。测试期约 10–15 分钟。

## 你需要准备

1. 一台装了 SillyTavern（≥1.12.0）的电脑；
2. 插件压缩包 `continuity-st-test-build.zip`（创始人提供）；
3. （可选，测「唤起」功能时）先运行网页版：`python -m continuity.webui`。

## 安装（2 分钟）

1. 解压 zip，把里面的 `continuity-st` 文件夹放到：`SillyTavern\data\default-user\extensions\`（多用户环境则放 `data\<你的用户名>\extensions\`）；
2. 重启 SillyTavern 或在扩展面板刷新，勾选启用 **「Continuity 体检」**。

## 测试五步（每步做完记一下结果）

| # | 做什么 | 期望看到 |
|---|---|---|
| 1 | 打开扩展面板，找到「Continuity 体检」 | 面板显示版本徽标 |
| 2 | 打开一个有聊天记录的角色，点「开始体检」 | 出现体检结果列表（每项都是“提示/疑似/建议”语气，不带吓人结论） |
| 3 | 点「打开本地 Web UI」 | 浏览器新标签打开 `http://127.0.0.1:8777/`（若没开网页版，会看到友好提示） |
| 4 | 在聊天输入框输入 `/continuity` | 触发同一个体检面板 |
| 5 | 打开设置页，把端口改成 9000 再改回 8777 | 修改被记住（重启后仍生效） |

## 请反馈这 6 条

1. 安装/启用是否顺利？（卡在哪一步）
2. 体检提示看得懂吗？有没有让你误解或害怕的表述？
3. 「打开本地 Web UI」按钮按预期工作吗？
4. 你愿意装这样一个扩展的原因/不愿意的原因？
5. **一周后你还想打开它吗？**（这是最重要的一个问题）
6. 其它任何意见。

> 隐私说明：本插件只读取内存、不写文件、不联网（仅打开本地 127.0.0.1 页面）、不碰你的密钥。可在浏览器 F12 Network 面板验证零外部请求。
